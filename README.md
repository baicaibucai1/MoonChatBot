# MoonChatBot — QQ 机器人管理面板

> **[English](README.en.md) · 中文**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-lightgrey.svg)
![Node](https://img.shields.io/badge/node-%3E%3D18-brightgreen.svg)

本地运行的可视化管理工具：**多个 QQ 机器人 + 角色人设/记忆文档 + 任意 OpenAI 兼容模型**，并内置「面板管理员 AI」、「心跳任务」、「精彩时刻」等自动化能力。所有功能都在一个无需构建、纯原生前端的 Web 面板里完成。

```
QQ 用户发消息 → 机器人连接层（qq-guild-bot，WebSocket）
   → 组装人设(memory/<id>/*.md) + 最近会话
   → 调用绑定模型（DeepSeek / 硅基流动 / 智谱 / Ollama…）
   → 自动回复并写入会话记录
   → Web 面板(http://127.0.0.1:4357)统一查看与运维
```

## 🚀 快速部署（GitHub 下载后 3 步上手）

**Windows**：双击根目录 **`安装并启动.bat`** —— 自动 `npm install` → 用示例生成缺失的 `config.json` / `.env`（**不会覆盖已存在文件**）→ 启动面板并打开浏览器。

**macOS / Linux**：

```bash
npm install
npm run setup     # 一键初始化：检查依赖 + 自动生成缺失的示例配置
npm start
```

然后二选一完成凭据：
1. 编辑 `config.json`（机器人 AppID、绑定模型）与 `.env`（QQ Secret、模型 Key）；或
2. 直接打开 **http://127.0.0.1:4357**，在面板「机器人 / 模型」页里可视化添加（保存即落盘）。

> 需要联网搜索/浏览器能力时，Playwright 首次使用会自动准备浏览器内核；长期运行可用 `pm2 start server.js --name moonchatbot-panel` 守护。

## 🖥 桌面版（可选）

面板默认在浏览器里用。如果你想要一个**独立窗口**（有自己的任务栏图标、开始菜单项，不跟浏览器标签页混在一起），仓库里带了一层 Tauri 桌面壳，源码在 [`desktop/`](desktop/README.md)。

**壳与服务是分开的** —— 这一点是刻意设计：

```
┌─ 后端服务（常驻，必须先在跑）────────┐
│  node server.js                      │
│  http://127.0.0.1:4357               │
│  含 Playwright 内核、机器人长连接      │
└──────────────────────────────────────┘
              ↕ HTTP（服务端已放行跨域）
┌─ 桌面壳（约 8 MB / 安装包 1.18 MB）──┐
│  WebView2 加载内嵌前端                │
│  从 tauri.localhost 调上面的 API      │
└──────────────────────────────────────┘
```

这么拆的好处很实在：壳不用背 Playwright（701 MB）和 Rust 运行时，**安装包只有 1.18 MB**；服务想重启、想看日志、想 `pm2` 守护都不受壳影响。

- **用法**：先双击 `启动面板.bat` 起服务，再打开开始菜单里的「MoonChatBot」。顺序反了也不会白屏 —— 壳会显示「无法连接后端服务」并给「重试连接」按钮。
- **从源码打包**：双击 `desktop/打包桌面版.bat`；编译器依赖（Rust + MSYS2/MinGW-w64）脚本会自动准备，**不需要管理员权限、不需要 Visual Studio**。
- **跨域说明**：Windows 上 WebView2 的页面来源是 `http://tauri.localhost`，所以 `server.js` 里加了一层跨域白名单（仅放行 `tauri.localhost` 与本地开发端口，非通配符）。这也是为什么把前端换到桌面壳后**服务端必须一起更新**。
- 详细设计取舍、验证记录与已知限制见 **[`desktop/README.md`](desktop/README.md)**。

## 🧩 功能详解

### 0. 侧栏导航（排序 / 收藏 / 位置记忆）

左侧角色列表不是固定的字典序 —— 它按你的使用习惯自动整理：

- **最近对话优先**：按每个角色所有线程里最后一次对话的时间降序排列，刚聊过的就在手边（没有任何对话的角色排最后）。
- **右键收藏**：在角色上右键 → 「收藏此角色」，被收藏的**钉在列表最上面**，且收藏组内照样按最近对话排序；再右键一次取消。收藏是本机的界面偏好，存在浏览器 `localStorage`、**不写进 `config.json`**，也不会同步到别的机器。
- **回到上次的位置**：记住你最后停留的「角色 + 标签页 + 对话线程」，刷新或重开面板直接还原（中途停在设置/模型页不会把它冲掉）。若记住的线程已被删除，会退回该角色最近的对话而不是停在空白区。

### 1. 角色管理

- **多实例**：左侧栏可添加任意数量的 QQ 机器人，每个独立的 AppID/Secret、沙箱/正式环境、绑定模型互不影响。
- **实时状态灯**：🟢 已连接 / 🟡 正在对话 / 🔴 掉线或出错，侧栏与卡片同步。
- **信息卡片**（进入机器人后首卡）：
  - 头像（支持 URL / emoji / 上传本地图片存到 `avatars/`）；
  - 名称、「正在操作」标识、连接状态徽标、AppID；
  - 四个信息格：绑定模型、历史记忆条数、Key 引用、记忆文件数；
  - 底部状态条：环境（正式/沙箱）、联网开关状态、搜索方式、运行状态。
  - **精彩时刻**区（见 §8）。
  - 背景动效画布（见 §10）。
- **操作**：`↻ 重连` 重挂机器人、`✎ 编辑` 进入完整编辑表单（AppID/Secret/模型/历史条数/环境/联网/搜索方式/头像）、`删除`（二次确认）。

### 2. 记忆库（memory/<机器人ID>/）

每个机器人一份独立的 Markdown 记忆库，由多个文件组成，回复时会作为系统提示人设读取。

- **记忆文件**：默认含人格/剧情/内容等，可**逐文件启用/禁用**、编辑正文、写备注、删除。
- **采用全局设定**：卡片内开关。勾选时先读取「设置 → 全局设定」的用户设定与提示词再读本库记忆；取消则只用本库。
- **AI 归档**：在输入框概述一段新剧情/内容，AI 自动归类写入对应记忆文件。
- **分支管理**：记忆/会话内容可从某条历史重新开分支，便于回切与重写剧情。
- **打开文件夹**：直接打开系统文件管理器定位到该机器人的记忆目录。

### 3. 会话记录

- **气泡会话流**：区分用户/机器人，内容按 Markdown 渲染（标题、列表、代码块、引用）。
- **自动滚动**：进入时自动定位到最新消息；你上翻查看历史时不会被新消息打断，回到底部后自动跟随。
- **单条操作**：每条消息可 `✕` 删除（AI 将不再读到），或 `⑂` 从该条开新分支。
- **卡片工具**：`⛶ 展开`（全屏查看完整记录）、`⑂ 分支`（管理对话分支，支持回切/恢复）、`⬇ 导出`（纯文本导出）、`清空`（二次确认）。
- **直接对话**：卡片底部输入框可直接与机器人对话，不走 QQ，用于快速验证人设与模型（「思考中…」占位气泡 + 完成后自动回落）。

### 4. 主动发消息

在机器人页面底部可主动发送消息：选择 **单聊 / 群聊 / 频道**，填写目标 openid（默认自动填入**主 ID**——第一个与你对话的人），内容支持自由文本。

### 5. 模型接入与用量

- **模型列表**：左侧「▤ 模型」进入。每个模型 = 一个 OpenAI 兼容端点（Base URL + 模型名），Key 通过 `.env` 环境变量（`apiKeyEnv`）或面板直填引用。
- **一键测试**：`POST /api/models/:id/test`，面板按钮验证连通性。
- **绑定**：机器人可任意切换模型，不绑定则不回复。
- **Token 统计**（设置 → 用量统计）：累计/今日 Tokens、调用次数、失败数，按机器人横向条形图与近 14 天柱状图，数字滚动动画展示。

### 6. 联网搜索（function calling）

- 全局开关与**搜索分级**：`自动`（轻量优先，不足时升级浏览器）、`仅轻量`（HTTP 抓标题/摘要）、`仅浏览器`（无头浏览器搜索）。
- **机器人单独覆盖**：编辑机器人时可独立设定是否允许联网与分级方式（机器人 > 全局）。
- 模型按需调用工具：需要正文时会自动用浏览器抓取网页内容。

### 7. 心跳任务（机器人主动发言）

角色页面底部「♥ 心跳任务」。**一张卡片 = 一个独立任务**，数量不限，可同时混用不同模式：

- `⏱ 间隔`：每隔 N 分钟自动说一句（最小 5）。
- `🕘 定时`：每天循环的时间点排布，每个时间点可填独立任务提示词。
- `🎲 随机`：在设定的最小/最大分钟范围内随机触发。
- **提示词**：每张卡可写自定义内容（会以「心跳任务」指令注入角色人设执行）；未写则按语气（问候/推进剧情/互动提问）自动生成。
- **状态**：卡片标题栏显示「已启用 N 个 · 最近一次约 X 分后」与主 ID；停用的卡自动降饱和。

### 8. 记忆画廊 ✨

AI 提炼的角色**高光片段**独立成一个标签页（角色卡片上的第二行就是它的前身，现已整体搬迁），
以卡片网格铺开 —— 摘要与台词**直接可见**，不用再逐条点开：

- **入口**：进入角色后点标签页「画廊」。
- **触发提炼**：画廊右上角「✨ 总结精彩时刻」（已有时显示「↻ 重提炼」）；也可让「面板管理员」说「总结 BOT1 的精彩时刻」。
- **数据来源**：记忆档案（前若干启用文件）+ 最近 16 条对话，交给绑定模型按「剧作编辑」角色提炼，**恰好 3 条**（标题 + 一句话看点 + 代表台词）。
- **管理**：每张卡右上角 `✕` 删除（二次确认），重新提炼会整组覆盖并自动落盘到 `config.json`。
- 窄屏自动改为单列。

### 9. 工作区（管理员 AI 的草稿台）

侧栏「▤ 工作区」是给「面板管理员」用的**草稿区**：先把内容生成出来放着，确认有用再注入，避免 AI 直接改坏记忆。

- **生成**：让管理员产出草稿（设定文案、剧情片段、人设补充等），落到工作区。
- **沉淀**：每条草稿可改名、预览、删除，独立保存互不干扰。
- **注入**：选中一条草稿 → 「⤓ 注入…」→ 选择目标（全局设定 / 某个角色的某个记忆文件），两步确认后写入；面板会留下「已注入」台账，可核对。

### 10. 面板管理员（AI Agent）

侧栏金色入口「◈ 面板管理员」打开内嵌 AI 助手控制台：

- **能力**：列出/读取机器人、模型与全局配置；读取某机器人记忆文件与会话；记忆全文关键词搜索；给出**修改建议**。
- **安全写入模型**：所有修改走「待确认」——管理员只生成建议（`propose_memory_edit / propose_global_edit / propose_bot_config_edit`），面板出现操作条，你点**确认写入**才真正落盘；可忽略或改。
- **总结与提炼**：提供 `summarize_moments`（写精彩时刻）等工具；也可让管理员帮你改写提示词、梳理剧情、做内容总结。
- **会话持久化**：右侧历史列表保存每次对话，跨多次打开可继续；「新对话」随时重开。
- **统一流式输出**：回复固定走流式 SSE（打字机效果），不再提供「流式/普通」手动开关 —— 是不是流式取决于环境能力而非个人偏好；遇到掐断长连接的内嵌预览时会自动降级并给你提示。
- **固定准则**：管理员提示词核心部分写死不可改（见设置 → 联网 → 面板管理员说明），并明确其只读评估的职责边界。

### 11. 外观与界面

- **品牌标识**：浅蓝色弯月 SVG（`public/logo.svg`），同时用作浏览器标签页图标与侧栏标识。

- **主题色**：预设金色（默认）/ 蓝 / 绿 / 紫 / 红 / 青 / 橙 / 粉，或取色器自定义；全站自动联动。
- **明暗主题**：☀/☾ 一键切换（记忆保存），深浅两套完整设计。
- **卡片背景动效**（作用于机器人信息卡）：`🌊 像素海浪`、`✨ 流光`、`🖥 黑客雨`、`☄ 流星`、`◽ 纯净`。
- **界面风格**：玻璃卡片 + 顶部釉光 + 立体按钮与开关、金色悬停反馈；设置页分组 Tab（外观 / 联网 / 全局设定 / 用量统计）避免内容堆叠。

### 12. 数据与存储

| 数据 | 位置 | 说明 |
|------|------|------|
| 面板与机器人配置 | `config.json` | 端口、机器人列表、模型列表 |
| 密钥 | `.env` | QQ Secret、模型 API Key（或 `config.json` 内 `env:变量` 引用） |
| 角色记忆 | `memory/<id>/*.md` | 人设与剧情档案（随消息自动归档） |
| 会话历史 | `memory/<id>/sessions.jsonl` | 每行一条 JSON 会话 |
| 全局设定 | `memory/global/*.md` | 用户设定、全局提示词（可逐文件开关） |
| 用量统计 | `memory/usage.jsonl` | Token 调用流水 |
| 头像 | `avatars/` | 面板上传的本地头像 |
| **本机界面偏好** | 浏览器 `localStorage` | 侧栏收藏、上次停留位置、主题色等 —— **只在本机生效**，不随 `config.json` 同步 |

> 以上运行期数据默认**不提交**到 Git（见 [配置与安全](#配置与安全重要)）。

## 配置与安全（重要）

| 文件 | 用途 | 是否提交仓库 |
|------|------|------|
| `config.json` | 端口、机器人、模型 | **否**（含凭据，已 gitignore） |
| `.env` | QQ Secret、模型 API Key | **否**（已 gitignore） |
| `memory/` | 角色记忆、对话记录 | **否**（已 gitignore） |
| `avatars/` | 上传的头像 | 否 |
| `config.example.json` / `.env.example` | 公开占位模板 | 是 |
| `dist-setup/` | 桌面版安装包 | 否（编译产物，走 Releases） |
| `desktop/src-tauri/target/` | Rust 编译中间产物（单次约 4 GB） | **否**（已 gitignore） |

- 服务默认只监听 `127.0.0.1`，面板仅供本机使用。
- 跨域只对桌面壳与本机开发端口开放白名单（`tauri.localhost`、`localhost:1420`），不是 `*`。面板本身不需要跨域，同源直接访问。
- 密钥支持两种写法：直接填在 `config.json`，或用 `env:变量名` 引用 `.env`（推荐，避免面板文件内明文）。
- 面板虽然会回显密钥便于编辑，但数据只在本机流转。
- 发布/共享本仓库前，请确认上述运行期文件未被加入版本库；`.gitignore` 已默认排除。

## 常见问题

- **面板打不开**：确认 `npm start` 成功、端口 4357 未被占用；Windows 双击 `安装并启动.bat` / `启动面板.bat` 可自检端口并自动打开浏览器。
- **机器人连接不上**：确认 `.env` 的 Secret、面板卡片上 AppID 无误，看终端日志。
- **不回复 / 报错**：先确认该机器人已绑定模型、对应 `apiKeyEnv` 的 Key 有效（面板「模型」页可一键测试）。
- **想让机器人更贴合人设**：编辑 `memory/<id>/persona.md`（人格）、plot（剧情）等记忆文件；勾选/取消「采用全局设定」控制是否叠加全局提示词。
- **新节点后想继续剧情**：在「会话记录」用分支从历史回切，或在记忆文件里补充概述并 AI 归档。
- **桌面壳显示「无法连接后端服务」**：正常现象，说明 `node server.js` 没在跑。先起服务再点壳里的「重试连接」。**别只改前端就重启壳** —— 跨域白名单在服务端，服务需要一起跑新版。
- **`打包桌面版.bat` 失败**：先看 `desktop/环境自检报告.txt`，它会列出 Rust / MSYS2 / WebView2 各自的状态；首次编译 Rust 依赖较慢，属正常。

## 更新日志

### v1.1.0 — 侧栏智能化 + 记忆画廊 + 品牌标识

**新增**

- **侧栏排序**：角色按「最近对话」降序排列，刚聊过的人就在手边。
- **右键收藏**：角色上右键收藏，**钉在列表最上面**（收藏组内仍按最近对话排序）。
- **位置记忆**：记住「角色 + 标签页 + 对话线程」，重开面板直接回到上次离开的地方。
- **记忆画廊**：原本挤在角色卡片第二行的「精彩时刻」升级为独立标签页，卡片网格呈现，摘要与台词直接可见。
- **工作区**：管理员 AI 的草稿台 —— 生成 → 沉淀 → 按需注入到角色记忆。
- **品牌标识**：浅蓝色弯月 SVG logo（`public/logo.svg`），兼作浏览器标签页图标。

**调整**

- 面板管理员对话去掉「流式/普通」切换，统一流式输出（环境不支持时自动降级）。
- 心跳任务取消「每个角色最多 3 个」的数量限制。

**修复**
